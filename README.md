[![License: GPL-3.0](https://img.shields.io/badge/License-GPLv3-blue.svg)](LICENSE)
[![Platform](https://img.shields.io/badge/Platform-Android-green.svg)]()
[![Language](https://img.shields.io/badge/Language-Kotlin-orange.svg)]()

**InstaSaver** is an open-source Android application built with Kotlin that allows users to easily download Instagram Reels, posts, and profile pictures directly to their device.

---

## Features

- **Reels Downloader:** Download Instagram Reels in high quality with a single tap.
- **Profile Picture Saver:** View and download full-resolution profile pictures (DP).
- **Fast & Lightweight:** Built using modern Android architecture and 100% Kotlin.
- **Privacy Focused:** Respects user privacy without storing sensitive data.
- **Clean UI:** Simple and intuitive interface for seamless downloading.
